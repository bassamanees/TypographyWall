تحديث اللوح الطيني وتتبع اليد فقط
================================
هذه النسخة تستخدم Python 3.14 وتكشف اليدين فقط؛ تتبع الجسم والظل متوقف.
كاميرا 640×480 مع نموذج يد واحد وتنعيم الحركة لتخفيف الحمل.
خلفية طينية ثابتة مع كتابة غائرة. معاينة الكاميرا داخل النافذة نفسها؛ C لإظهارها.
تم تعديل معالجة تغيير حجم النافذة لتفادي إعادة إنشائها المتكررة.
افتح main.py بالمفسر نفسه. المكتبات لم تتغير.
أثر الحركة القديم V متوقف للحفاظ على وضوح الطين.

الجدار الحي — إصدار Python 3.14
==============================

1) فك الضغط وافتح مجلد p1 في PyCharm.
2) اختر بيئة افتراضية جديدة يكون مفسرها الأساسي Python 3.14.
3) في الطرفية الخاصة بهذه البيئة نفذ:

python --version
python -m pip install -r requirements.txt
python main.py

يجب أن يظهر Python 3.14.x. استخدم المفسر نفسه لتشغيل main.py في PyCharm.
start.py يستعمل المفسر الذي اخترته؛ لا ينزل Python آخر ولا يبدل الإصدار.

بديل من طرفية Ubuntu داخل مجلد p1:
python3.14 -m venv .venv314
source .venv314/bin/activate
python -m pip install -r requirements.txt
python main.py

بعدها تستطيع اختيار .venv314/bin/python كمفسر للمشروع في PyCharm.
إذا لم تتوفر venv: sudo apt install python3-venv
إذا ظهر خطأ libGLESv2 أو libEGL: sudo apt install libgles2 libegl1

للفأرة: python main.py --mouse
للشاشة الكاملة: python main.py --fullscreen
لكاميرا أخرى: python main.py --camera 1
النماذج موجودة داخل models. هذا كود مصدر وليس ملفاً تنفيذياً مستقلاً.

الإيماءات
---------
• الكف المفتوحة تتحرك ببطء: الحروف القريبة تنحني باتجاه المسار.
• حركة سريعة بالكف: موجات تدفع الحروف وتتناثر ثم تهدأ.
• قرص أو قبضة قرب حرف/كلمة: إمساك وسحب؛ الإفلات أثناء الحركة يرمي العنصر.
• اسحب حرفاً لمسافة كافية: عناصر قريبة تتبعه على مسار إيدك كشريط كتابة.
• مدّ الكلمة: أمسك طرفها، ثم اقرص طرفها الثاني بالإيد الثانية وباعد ببطء.
  الكلمتان لا تتمددان معاً؛ الإيدين تمسكان الكلمة نفسها.
  أبقِ الإيدين بارتفاع متقارب. ابدأ بكلمة طويلة وواضحة.
• الكفان مفتوحتان وتتباعدان بسرعة: العرض التالي.
• الكفان مفتوحتان وتتقاربان بسرعة: العرض السابق.
• يكفي ظهور اليد للتفاعل؛ لا يوجد كشف جسم في هذه النسخة.
• الصور: الحركة بالكف المفتوحة تفرّق القطع؛ القبضة تجمع القطع القريبة.
• الهدوء دون ظل فعّال يرجع العناصر تدريجياً لمواضعها؛ الابتعاد يعيد اللوحة.

ملاحظات فنية مهمة
----------------
التمديد يحافظ على شكل أجسام الحروف عندما يجد وصلة رفيعة مناسبة ويمد الوصلة.
الكلمات التي لا تحتوي وصلة مناسبة تُمد أفقياً كصورة كاملة؛ هذا مؤثر بصري
وليس محرّك كشيدة لغوي كامل. التمديد محدود حتى 2.2 ضعف العرض.
التحول بين العربي والمسماري والصورة انتقال فني بين محتويات موجودة، وليس
ترجمة آلية أو تحويلاً لغوياً بين الحروف والرموز.
لا يوجد صوت أو تسجيل صوتي؛ المشروع تفاعل بصري بالكاميرا.

مفاتيح التحكم
-------------
B: تبديل الكلمات المتصلة / الحروف المنفردة. الكلمات هي الوضع الافتراضي.
0: إعادة ترتيب اللوحة الحالية.
F: شاشة كاملة.
الأسهم يمين ويسار: تبديل العرض.
1 / 2 / 3: عربي / مسماري / صورة لنفس الموضوع.
N: الموضوع التالي.
C: معاينة الكاميرا.
D: معلومات التتبّع والأداء.
K: معايرة مسافة التفاعل.
M: تبديل الكاميرا والفأرة.
G: شبكة التصميم.
V: غير مستخدم في نسخة الطين.
S: لقطة شاشة.
R: بدء / إيقاف تسجيل فيديو للوحة.
H: إظهار / إخفاء المساعدة.
Esc: خروج.

تجربة التمديد بالفأرة
-------------------
ابدأ بوضع الكلمات B. أمسك طرف كلمة بزر الفأرة الأيسر، واضغط Space
وأنت ما زلت ممسكاً: يتثبت طرفها الثاني بيد افتراضية. اسحب المؤشر ببطء
بعيداً عن الطرف المثبت. Space مرة أخرى يلغي اليد الثانية.
العجلة أو السهمان أعلى/أسفل يتحكمان بالقرب، والزر الأيمن يُظهر ظلاً تجريبياً.

أين تعدّل الكود؟
---------------
main.py: نقطة الدخول.
start.py: التشغيل بالمفسر المختار.
wall/texts.py: الكلمات والجمل والصور.
wall/config.py: السرعات والقوة وحجم المؤثرات.
wall/living.py: الفرشاة والشريط والموجات وتمديد الكلمات.
wall/elastic_ink.py: رسم تمديد وصلات الخط.
wall/transitions.py: انتقال الجزيئات.
wall/tracking.py: الكاميرا وتتبع اليد والجسم.
wall/interaction.py: تفسير الإيماءات والإمساك.
wall/particles.py: حركة العناصر وعودتها إلى الشبكة.
wall/rendering.py: الرسم.
wall/app.py: ربط الأجزاء ببعضها.

المكتبات والاختبار
-----------------
الإصدارات موجودة في requirements.txt والشرح في README.md.
تم تحديث التتبع إلى MediaPipe Tasks ليعمل مع Python 3.14.
pygame-ce يستعمل اسم الاستيراد pygame نفسه.
لا تثبت pygame أو opencv-python بجانب الحزم الموجودة في المتطلبات.
نجح 36 اختباراً على Python 3.14.8، إضافة إلى كشف يدين وجسم بصور اختبار.
لم يتم اختبار كاميرا حقيقية أو جهازك؛ الأداء الفعلي يحتاج تجربتك.
لتشغيل الاختبارات: python -m unittest discover -s tests -v
عند الخطأ انسخ رسالة الطرفية كاملة. التفاصيل في logs/wall.log.
